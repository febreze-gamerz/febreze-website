# Febreze Gamerz Website

Static portfolio website for `febreze.is-a.dev`.

## Add your profile picture

Put your image here:

`assets/pfp.png`

The website already points to that exact path. PNG/JPG is fine, but PNG is recommended.

## Files

- `index.html` — website content and links
- `style.css` — design, responsive layout and animations
- `script.js` — reveal animations and current year
- `assets/pfp.png` — **you add this yourself**

## Free hosting

This is a static site and can be hosted on GitHub Pages or Cloudflare Pages.
